
# First React Native App

A simple mobile application built using [React Native](https://reactnative.dev/) with TypeScript. This project serves as a starting point for learning and experimenting with mobile development.

## Features

- 🚀 Cross-platform: Runs on both iOS and Android
- 🧑‍💻 Written in TypeScript for type safety
- ⚡ Fast Refresh for instant updates during development
- 🛠️ Easily extensible and customizable

## Getting Started

Follow these steps to set up and run the app locally.

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or newer)
- [Yarn](https://classic.yarnpkg.com/en/docs/install/) or [npm](https://www.npmjs.com/)
- [Expo CLI](https://docs.expo.dev/get-started/installation/) (if using Expo)
- Android Studio/Xcode for running on an emulator or device (optional)

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/naeemcse/first-react-native-app.git
   cd first-react-native-app
     ```
2. **Install dependencies:
 ```bash
yarn install
# or
npm install
yarn start
# or
npm start
```
